# CowBot 0.1.14 — Thirteen interface languages, a default CowBot, and agent tags

CowBot 0.1.14 makes the desktop usable in every language of its picker, gives a
fresh workspace a primary agent out of the box, and lets team workspaces label
agent names. No database migration ships, so a workspace opened by 0.1.13 opens
unchanged.

## Changes

- **The interface ships in thirteen languages.** French, German, Hindi,
  Indonesian, Italian, Japanese, Korean, Brazilian Portuguese, Latin American
  Spanish, and European Spanish join English and the two Chinese catalogues.
  Each language is a complete typed catalogue, so a missing string fails the
  build rather than falling back silently. The picker lists every language in
  its own script, dates and times follow the choice, and **System** now resolves
  the first supported language in the operating system's preference list,
  including the Brazilian/European Portuguese split and the Latin American and
  European Spanish catalogues. Interface copy is translated; service
  diagnostics, agent profiles, templates, and stored audit reasons remain in
  English.
- **A new workspace starts with CowBot.** The built-in Main Assistant template
  now creates the primary agent as **CowBot**, and the desktop instantiates it
  automatically when a workspace has no agents. Its direct conversation is
  provisioned at the same time, so onboarding no longer requires adding the
  template by hand; the team step shows it as already added. Existing
  workspaces are not renamed or migrated.
- **First conversation naming.** While the main agent's direct conversation is
  empty and still named CowBot, the chat offers a one-time card to give it
  another name. Saving uses the ordinary agent editor, so the conversation
  title and mentions follow; **Keep CowBot** dismisses the card for that
  workspace on this device. Renaming later works from Settings → Team or the
  conversation's context menu.
- **Optional `bot` tags.** **Settings → General** gains an **Agent tags** switch
  that adds a small translated `bot` tag beside agent names in the sidebar, the
  direct-chat title, participant chips, message senders, approvals, typing and
  streaming rows, and Settings → Team. It is stored per device and off by
  default. The tag is presentation only: it never changes an agent's stored
  name, a mention, a task assignee, or a prompt. Team routing falls back to the
  default name CowBot, and to the legacy name `main` in older workspaces.

## Upgrade

- **Windows (NSIS setup):** updates in-app from 0.1.13.
- **Windows (MSI):** install the new NSIS setup or MSI manually.
- **macOS (from the DMG):** updates in-app. Builds remain unsigned and
  un-notarized, so macOS may ask you to allow CowBot again after an update.
- **Linux (AppImage):** updates in-app.
- **Linux (deb):** download and install the new package.

No database migration ships in this release: schema version 20 is unchanged, so
a database opened by 0.1.14 can still be opened by 0.1.13. Workspace packages,
prompt snapshots, usage rows, and model provider configuration are untouched.
Agents created before this release keep their current name; only an empty
workspace receives the CowBot default.

## Known limitations

The server and CLI bootstrap do not auto-provision the main agent yet; the
default is a desktop startup rule. See [the limitations page](../LIMITATIONS.md)
for the full boundary.
