# CowBot 0.1.13 — Sidebar update prompt and a white line icon

CowBot 0.1.13 changes only the desktop presentation: the update prompt moves
beside the conversation, the whole title bar drags the window, and the app icon
is redrawn as a white line mark. No Rust code and no database migration ship, so
a workspace opened by 0.1.12 opens unchanged.

## Changes

- **The update prompt sits above the account row.** A launch-time check that
  finds a new version now shows a rounded card in the sidebar footer instead of
  a strip across the top of the chat column. The card keeps the available,
  downloading, ready-to-restart, and failed states together, with the download
  action, a progress bar, and a **Later** dismiss. Manual checks still report in
  Settings → About.
- **The whole title bar drags the window.** The drag region now covers the title
  bar subtree, so the brand lockup and the space around the window controls drag
  the window. Minimize, maximize, close, and the inspector triggers stay
  clickable, and a double click still maximizes.
- **A white line app icon.** The cow mark is now a transparent, pure white line
  drawing with a cut-out eye and a heavier stroke, regenerated for every Windows
  tile size and `icon.ico` from
  [`assets/brand/cowbot-icon-white.svg`](https://github.com/BerryUIKI/CowBot/blob/main/assets/brand/cowbot-icon-white.svg).
  The macOS `.icns` keeps the previous artwork.

## Upgrade

- **Windows (NSIS setup):** updates in-app from 0.1.12.
- **Windows (MSI):** install the new NSIS setup or MSI manually.
- **macOS (from the DMG):** updates in-app. Builds remain unsigned and
  un-notarized, so macOS may ask you to allow CowBot again after an update.
- **Linux (AppImage):** updates in-app.
- **Linux (deb):** download and install the new package.

No database migration ships in this release: schema version 20 is unchanged, so
a database opened by 0.1.13 can still be opened by 0.1.12. Workspace packages,
prompt snapshots, usage rows, and model provider configuration are untouched.

## Known limitations

Unchanged from 0.1.12; see [the limitations page](../LIMITATIONS.md).
