# CowBot 0.1.15 — Sidebar layout fix

CowBot 0.1.15 fixes the desktop sidebar sliding sideways and clipping its own
content. It is a single fix with no new features and no database migration, so a
workspace opened by 0.1.14 opens unchanged.

## Fixes

- **The sidebar no longer pans horizontally.** The column is a fixed 296px with
  no resize handle, so it must never scroll sideways — but it did, sliding rows
  and background task cards out of the column and cutting them off at both
  edges. The background task card had no `min-width`, so it resolved to
  `min-width: auto` and refused to shrink below its content width: a nowrap
  title, a nowrap activity line, and a 160px branch chip sized it 99px wider
  than its track. Because a scroller set to `overflow-y: auto` computes the
  other axis as `auto` too, that overflow turned the whole sidebar into a
  horizontal scroller rather than being clipped. The layout now constrains the
  card instead of only hiding the overflow: the card and its meta row shrink,
  the branch chip ellipsizes first, and the elapsed time keeps its width. Long
  names and paths truncate with an ellipsis and the full text stays in a
  tooltip. An explicit `overflow-x: hidden` remains as a guard, so a future wide
  descendant clips rather than widening the column.
- **The conversation participant picker no longer widens the sidebar.** It had
  the same defect: a `fieldset` defaults to `min-width: min-content`, so a long
  agent name pushed the picker past the column. It now shrinks like the rest of
  the sidebar, and a long name ellipsizes.

Sidebar content that genuinely does not fit is truncated or ellipsized rather
than turned into a horizontal scroller, and vertical scrolling is unchanged.

## Upgrade

- **Windows (NSIS setup):** updates in-app from 0.1.14.
- **Windows (MSI):** install the new NSIS setup or MSI manually.
- **macOS (from the DMG):** updates in-app. Builds remain unsigned and
  un-notarized, so macOS may ask you to allow CowBot again after an update.
- **Linux (AppImage):** updates in-app.
- **Linux (deb):** download and install the new package.

No database migration ships in this release: schema version 20 is unchanged, so
a database opened by 0.1.15 can still be opened by 0.1.14. Workspace packages,
prompt snapshots, usage rows, and model provider configuration are untouched.

## Known limitations

Unchanged from 0.1.14; see [the limitations page](../LIMITATIONS.md).
