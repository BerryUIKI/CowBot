Archived release notes for published CowBot versions. GitHub Releases remains
the canonical distribution point; these files keep the notes in the repository.

| --- | --- |

| [0.1.2](0.1.2.md) | Automatic updates, signed update channel, and a simplification pass |

| [0.1.0](0.1.0.md) | First public preview of the local/offline MVP |
